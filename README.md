# Dispute Paisa Landing Page

Built with:
- React + Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- Inter font

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```

## Important

The query submission currently runs in **demo/local mode** and does not send real customer data anywhere. Connect the form to Google Forms/Sheets, a backend API, or another secure data service before production use.

The displayed query reference ID is also demo-only until connected to a real persistence system.

Replace placeholder contact details and any sample testimonial content with verified business information before publishing.
